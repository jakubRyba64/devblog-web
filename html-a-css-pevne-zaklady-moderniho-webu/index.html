    HTML a CSS: pevné základy moderního webu

    Publikováno (10. února 2026)

    Přejít na část

    Struktura stránky v HTML Stylování pomocí CSS Responzivní design Osvědčené postupy

    Každá webová stránka stojí na dvou technologiích: HTML dává obsahu strukturu a CSS určuje, jak bude vypadat. Bez jejich pochopení se později ztratíte v každém frameworku.

    Dobrá zpráva je, že základy zvládnete rychle. Stačí pochopit pár principů a hlavně si je hned vyzkoušet ve vlastní stránce.

    V tomto článku si projdeme, jak postavit přehlednou strukturu stránky a přizpůsobit ji mobilu i počítači.

    1 — Struktura stránky v HTML

    HTML popisuje význam obsahu. Hlavička stránky patří do header, navigace do nav, hlavní obsah do main a části obsahu do section a article.

    Sémantické prvky nejsou jen o úhlednosti. Pomáhají vyhledávačům, čtečkám pro zrakově postižené i vám samotným při orientaci v kódu.

    Cvičení: napište stránku o sobě s hlavičkou, odstavci, seznamem a obrázkem — a to jen pomocí sémantických značek, bez jediné třídy.

    2 — Stylování pomocí CSS

    CSS vybírá prvky pomocí selektorů a nastavuje jim vlastnosti — barvy, velikosti, mezery i rozložení. Základní jednotkou je pravidlo: selektor a složené závorky s vlastnostmi.

    Nejdůležitější pojmy na začátek jsou kaskáda (které pravidlo vyhrává), dědičnost a box model — tedy to, jak se k šířce prvku počítají odsazení a okraje.

    Pro rozložení stránky se dnes používá Flexbox pro jednorozměrné řady a CSS Grid pro mřížky. Oba zvládnete na pár malých příkladech.

    3 — Responzivní design

    Responzivní stránka se přizpůsobí obrazovce — od mobilu po velký monitor. Základem je meta značka viewport a jednotky, které se umí počítat s dostupným místem.

    Pomocí media queries měníte rozložení podle šířky obrazovky: na mobilu stojí prvky pod sebou, na desktopu vedle sebe.

    Pravidlo, které se vyplácí dodržovat: navrhujte nejprve pro mobil a teprve pak přidávejte úpravy pro větší obrazovky. Ušetří vám to spoustu přepisování.

    4 — Osvědčené postupy

    Pojmenovávejte třídy podle významu, ne podle vzhledu. Třída article-card vydrží, i když změníte design; modry-nadpis ne.

    Oddělujte strukturu od vzhledu: HTML nese obsah, CSS stylování a JavaScript chování. Toto pravidlo vám ušetří hodiny hledání, kde se co změnilo.

    Stránku pravidelně zkoušejte v prohlížeči, ideálně i v mobilním rozlišení. Chyby v layoutu se nejsnáze opravují hned, jak vzniknou.

    Stejný obsah, jiné rozložení — o tohle jde v responzivním designu
